PXAB PRN Dashboard

This repository contains a single interactive HTML dashboard for North Carolina Medicaid behavioral health measures.

Files:
- nc_medicaid_bh_dashboard.html  — A standalone HTML dashboard (open in a web browser). No server or build step required; just double-click the file or open it in your browser.
- readme.txt  — This file (updated to describe repository contents).

Notes:
- The dashboard is a self-contained HTML file. Any data displayed in the dashboard is embedded or loaded by the HTML file itself; source data files are not included in this repository.
- If you want to update or regenerate the dashboard, open the HTML in a text editor or a web development environment and edit the embedded code.
